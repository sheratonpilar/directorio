# Directorio de servicios — Sheraton Pilar

Sitio estático. El contenido se edita en el Google Sheet "Directorio_Servicios" y se publica
con el menú **Directorio ▸ Publicar**, que reescribe `data/directorio.json`.

- `index.html`, `directorio.css`, `directorio.js`: el sitio (no se tocan para cambiar contenido).
- `data/directorio.json`: lo genera el Apps Script. No editar a mano.
- `img/`: fotos opcionales de sección (columna `foto` de la hoja `secciones`).
